Solução de Acessibilidade

Um sistema automatizado projetado para auxiliar pessoas com deficiência visual a realizarem a travessia de vias urbanas de forma autônoma e segura.

Card 2

O Desafio Urbano

Qual é o problema atual nas travessias?

🔄 Clique para ver a imagem

Falta de sinalização sonora adequada nas cidades, gerando insegurança e risco permanente para pedestres com baixa visão.

Card 3

A Solução Técnica

Como o semáforo avisa o pedestre?

🔄 Clique para testar o som

O acionamento por botão gera bipes sonoros temporizados que mudam de ritmo conforme o tempo de travessia.

Montagem e Circuito

Quais componentes são utilizados?

🔄 Clique para ver o esquema

Construído com microcontrolador Arduino, sensores de travessia, leds sinalizadores e sonorizador Buzzer.
